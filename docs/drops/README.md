# Drop notes

The working material behind the weekly announcements, kept in the open so the
claims in the posts can be checked against the tools they describe.

- [`POSTS.md`](POSTS.md): the eight LinkedIn posts, one per weekly drop.
- [`TOOL-SUMMARIES.md`](TOOL-SUMMARIES.md): a plain-English summary of every
  tool, including the ones that share a drop, with the install line and the
  honest limitation for each.

Everything in the repo is downloadable from day one. The weekly schedule is
when each tool gets *written about*, not when it becomes available.
